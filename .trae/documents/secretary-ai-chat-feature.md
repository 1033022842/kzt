# 秘书智能体 AI 对话 — 前端演示版

## 概述

在秘书智能体面板中新增一个 AI 对话卡片，纯前端假数据演示。用户输入问题后，前端根据关键词匹配，用已有的模拟数据生成自然语言回复，模拟"和 LLM 对话"的效果。

**只改一个文件**，零后端修改。

## 拟修改文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `frontend/src/views/StreamerEditor.vue` | 修改 | 秘书面板新增对话 UI + mock 回复逻辑 |

---

## 实现方案

### 1. 新增数据结构（`<script setup>` 中）

```js
const secretaryMessages = ref([])
const secretaryInput = ref('')
const secretaryAsking = ref(false)
const secretaryChatRef = ref(null)
```

### 2. Mock 回复函数

`mockSecretaryReply(userMessage)` — 根据用户输入关键词匹配，返回预设的自然语言回复。利用页面已有的数据：

- `myConfigs` — 当前账号所有智能体配置
- `mockSettlementData` — 结算模拟数据
- `marketingLogs` — 营销运行日志
- `groupedConfigs` — 已按类型分组的智能体

**关键词 → 回复策略**:

| 关键词 | 回复内容来源 |
|--------|------------|
| 多少/几个/数量/智能体 | 统计 `myConfigs` 各类型数量，返回概览 |
| 营销/推广/账号 | 列出营销智能体名称 + 绑定账号数 |
| 库存/进销存/进货 | 列出进销存智能体 + 库存数据 |
| 结算/数据/盈利/报表 | 用 `mockSettlementData` 生成结算报告 |
| 配额/余额/还能 | 读取用户配额信息 |
| 运行/状态/日志 | 用 `marketingLogs` 生成状态报告 |
| 秘书/TG/频道/汇报 | 列出秘书智能体配置 |
| 默认 | 通用回复，提示可问的问题 |

### 3. 发送逻辑

```
sendSecretaryMessage():
  1. 空输入 → return
  2. 用户消息 push 到 secretaryMessages (role: 'user')
  3. secretaryAsking = true
  4. setTimeout 0.8-1.5s 模拟"思考延迟"
  5. 调用 mockSecretaryReply() 生成回复
  6. 回复 push 到 secretaryMessages (role: 'assistant')
  7. secretaryAsking = false
  8. 滚动到底部
```

### 4. UI 布局

在秘书面板"今日结算数据预览"卡片**下方**，新增一张卡片：

```
┌─────────────────────────────────┐
│ 🤖 AI 秘书对话                  │
├─────────────────────────────────┤
│                                 │
│  [欢迎消息 / 对话历史]          │

│  └──────────────────┘          │
```

- Enter 发送，Shift+Enter 换行
- 加载中显示 "秘书思考中..." 占位

## 关键决策

1. **纯前端实现** — 不依赖后端 API，不改任何后端代码
2. **关键词匹配** — 用简单规则生成看起来像 LLM 的回复，无需真实 AI
3. **复用已有数据** — `myConfigs`、`mockSettlementData`、`marketingLogs` 等已存在于页面中的变量
4. **延时模拟** — `setTimeout` 模拟网络请求和 AI 思考时间
5. **不持久化** — 对话仅在当前页面会话中保留，刷新即清空

## 验证步骤

1. 启动前端开发服务器
2. 登录后切换到"秘书类"智能体面板
3. 看到"AI 秘书对话"卡片和欢迎消息
4. 输入"我有多少个智能体？" → 验证回复
5. 输入"营销情况怎么样？" → 验证回复
6. 输入"今天的结算数据？" → 验证回复
7. 观察延迟效果和气泡样式
